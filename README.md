# BeamMP Server Launcher

A simple launcher for quickly configuring `ServerConfig.toml`.

## Features
- **Server Setup**: Easily set your Server Name, IP, Max Players, and AuthKey.
- **Map Selector**: Choose your map visually with preview icons.
- **One-Click Launch**: Start and Stop your server directly from the launcher.
- **Single File**: Compact build that doesnt require .NET installation on the user's side.

## How to Use
1. Download the latest release (ZIP).
2. Extract all files into your BeamMP Server root folder (where `BeamMP-Server.exe` is).
3. Run `BeamMPLauncher.exe`.
4. Configure your settings and hit **Launch Server**.

## How to Build (For Developers)
If you want to build it yourself, just run `build.cmd`. It will generate a single-file executable in `bin/Dist`.
